# Pizzeria Kotlin - Semana 3

## Asignatura
Desarrollo App Moviles I (PMY2201) - Duoc UC

## Descripcion
Aplicacion de consola desarrollada en Kotlin/JVM para
gestionar clientes, productos, pedidos e inventario de
una pizzeria.

El proyecto continua el trabajo realizado en Semana 2.

## Funcionalidades
- Validacion de correos y telefonos mediante Regex.
- Validacion de cantidades y promociones con Ranges.
- Anotacion personalizada @Promocionable.
- Reflection sobre las clases Cliente y Pedido.
- Sobrecarga del operador + para combinar pedidos.
- Comparacion de productos mediante ==.
- Desestructuracion de Cliente y Pedido.
- equals() y hashCode() para evitar duplicados.
- Calculo de descuentos, IVA y total del pedido.
- Control de inventario y asignacion de repartidores.
- Resumen de operaciones en consola.

## Tecnologias
- Kotlin/JVM
- IntelliJ IDEA
- JDK 21
- Kotlin Standard Library 2.1.0

## Ejecucion
1. Abrir el proyecto en IntelliJ IDEA.
2. Configurar JDK 21 y Kotlin/JVM.
3. Incorporar kotlin-stdlib 2.1.0 si no esta disponible.
4. Abrir src/Main.kt.
5. Ejecutar la funcion main().
6. Ingresar los datos solicitados por consola.

## Observaciones
Los clientes, productos y fechas promocionales son
datos de ejemplo utilizados para demostrar los
requerimientos de la evaluacion.

La informacion se gestiona en memoria.
