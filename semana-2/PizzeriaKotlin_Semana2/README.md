# Pizzería Kotlin - Semana 2

Proyecto desarrollado para la asignatura Desarrollo App Móviles I (PMY2201).

## Descripción

Programa de consola en Kotlin que simula la atención de pedidos de una pizzería. Permite revisar los ingredientes disponibles, registrar pedidos y mostrar un resumen de las ventas del día.

## Funcionalidades

- Catálogo de pizzas con precios e ingredientes.
- Registro de clientes y validación de datos de contacto.
- Control de inventario y reposición de ingredientes.
- Cálculo de subtotal, descuento e IVA.
- Estados de pedidos y asignación de repartidores.
- Resumen de pedidos y manejo de entradas incorrectas.

## Tecnologías

- Kotlin/JVM
- IntelliJ IDEA
- JDK 21

## Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Revisar que el JDK esté configurado.
3. Abrir `src/Main.kt`.
4. Ejecutar la función `main()`.

Los datos de clientes, productos y repartidores son ejemplos. El programa trabaja en memoria y muestra los resultados en la consola.
